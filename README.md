# 基于计划—执行偏差分析的个人学习效率优化工具

`StudyPlanAnalyzer` 是一个纯本地 Windows 桌面软件。它把学习计划、执行记录和统计分析放在同一个闭环里，帮助用户观察计划时长与实际用时之间的长期偏差，并用规则生成下一次计划建议。

## 功能

- 本地 SQLite 数据库、用户注册/登录/退出和 PBKDF2-SHA256 密码保护。
- 多账号数据隔离：所有任务和执行记录查询都带当前用户 `user_id`。
- 学习计划 CRUD、搜索、日期/科目/状态筛选。
- 执行记录、完成程度、实际时长、时间偏差和偏差率。
- 首页统计、科目/任务类型/时间段统计和趋势图。
- 基于真实历史记录的个性化建议与相似任务计划时长推荐。
- 个人资料、昵称修改、密码修改、数据导出和清空个人学习记录。

## 安装与运行

```powershell
pip install -r requirements.txt
python main.py
```

也可以双击 `run.bat` 启动。数据库会自动创建在 `data/study.db`，没有预置演示数据。

## 项目结构

`database/` 负责表结构和连接；`services/` 负责业务与统计；`ui/` 负责登录、主窗口和页面；`widgets/` 负责可复用界面组件；`utils/` 负责密码和通用校验。

## 核心算法

时间绝对偏差为 `实际用时 - 计划用时`，偏差率为 `(实际用时 - 计划用时) / 计划用时 × 100%`。负偏差会结合完成程度解读，不直接等同于效率更高。没有记录时，统计和建议页面会显示引导信息。

## 网页版

项目同时提供无需安装前端依赖的本地网页版本，文件位于 `web/`。进入该目录运行 `run.bat`，然后打开 `http://127.0.0.1:8765`。网页数据保存在浏览器本地，适合本地演示和作品展示。

也可以直接双击项目根目录的 `run_web.bat`，它会启动本地网页服务并打开浏览器。
